# Midjourney Proxy 使用手册

- **适用版本**：v12.1.6
- **最后更新**：2026-10-28

## 手册信息

- **适用读者**：需要部署、接入、运维或二次开发 Midjourney Proxy 的开发人员、运维人员与技术支持人员。
- **前置条件**：具备 Docker 或 .NET 8 运行环境的基本操作能力，了解反向代理、进程与端口、日志排查等基础运维知识；阅读接口章节时需要具备 HTTP/JSON 调用经验。

## 产品定位

Midjourney Proxy 是一个统一的绘图代理服务：它以同一套 HTTP API 代理 Discord、悠船与 Midjourney 官网三种绘图后端，屏蔽不同后端在提交方式、任务轮询与结果回收上的差异。服务同时提供浏览器端管理后台，用于账号池、任务、用户与系统配置的集中管理。调用方只需面向本文档描述的接口约定开发，无需分别对接各后端。
