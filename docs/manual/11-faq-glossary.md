# 11 FAQ 与术语表

- **适用版本**：v12.1.6
- **适用读者**：所有使用与维护本产品的人员
- **前置条件**：无

本章汇总使用过程中反复出现的问题与统一术语，便于快速定位答案并在团队内保持一致表述。若问题涉及具体环境，请优先按第九章的排查路径收集信息。

## 使用建议
1. 先按主题定位 FAQ，再按答案中的章节引用查看详细步骤。
2. 涉及环境差异时，以实际配置、日志与接口返回为准，不要只凭术语推断。
3. 团队沟通时使用术语表中的统一叫法，避免把「实例」「账号」「渠道」混用。

```bash
# 查询任务状态（示例，Token 与任务 ID 使用占位符）
curl -fsS -H "Authorization: {token}" http://127.0.0.1:8080/mj/task/{taskId}/fetch
```

## 高频 FAQ
### 部署与启动
**Q1：最低需要什么配置？**
没有固定下限，按账号数、并发与是否本地存储评估。SQLite + 本地存储可用于小规模验证；生产建议独立数据库与 Redis，并为附件预留磁盘。具体容量以实际压测为准。

**Q2：服务监听哪个端口？**
应用默认监听 8080；Compose 示例映射为 `8086:8080`。对外应通过反向代理暴露 443，不要直接把应用端口暴露到公网。

**Q3：必须部署 Redis 吗？**
生产必须。任务队列、并发计数、分布式锁与多节点通知都依赖 Redis；Redis 不可用时缓存会退化到内存，但队列无法正常工作，系统设置也无法保存。

**Q4：哪些目录必须持久化？**
`data`（配置与 SQLite）、`logs`、`wwwroot/attachments`、`wwwroot/ephemeral-attachments`。容器重建时未挂载的目录会丢失。

**Q5：如何确认服务真的可用？**
`GET /health` 返回 200 只代表进程存活；还要检查数据库类型、Redis 状态、账号在线数与测试任务。依赖状态以日志和后台为准，不以健康端点单独判断。

### 账号与登录
**Q6：如何新增一个绘图账号？**
在管理后台新增账号，填写渠道 ID、服务器 ID、Token 或 Cookie，设置启用状态与并发/队列，保存后执行同步与重连。悠船与官网账号需要对应的凭据与功能开关。

**Q7：账号启用后为什么一直不在线？**
常见原因是凭据失效、频道填错、代理不通、触发风控，或当前不在工作时间/摸鱼时间。批量启用后后台最多约 1 分钟巡检启动，不要连续重复启用；具体排查见第九章第 1 节。

**Q8：并发与队列应该怎么设？**
单账号 `CoreSize` 默认 3，Excel 导入限制 ≤12；`QueueSize` 默认 10，Excel 导入限制 1–100；账号表单仅校验 ≥1，服务端没有同样上限。先增加账号与分散渠道，再考虑提高单账号并发；队列持续满应先排查消费能力。

**Q9：工作时间和摸鱼时间有什么区别？**
工作时间内容会创建实例并接收新任务；摸鱼时间只接收放大、变体、扩展、弹窗等变化任务，不接收新的绘图任务；两者之外会释放实例。

**Q10：Cloudflare 验证怎么处理？**
查看账号的验证 URL 与禁用原因，人工完成 challenge；配置验证服务器可自动处理，自动验证还需要 2Captcha 密钥与 Redis。反复重试会加重风控，详见第九章第 2 节。

**Q11：管理员登录用什么？**
使用管理员 Token。Token 由部署配置注入，必须在首次启动前注入强令牌；若未注入，首次登录后立即重置。演示模式可以空 Token 登录，生产绝不能开启。

### 接口调用与任务
**Q12：接口如何鉴权？**
普通调用在请求头携带 `Authorization: {token}`，也支持 `mj-api-secret`、`x-api-key`、`api-key`；管理员接口使用管理员 Token。演示模式跳过鉴权，访客模式允许未登录访问普通接口，私有化部署应关闭这两项。

**Q13：提交任务是同步出图吗？**
不是。提交成功只代表已入队或已提交上游，接口返回任务 ID；客户端应轮询任务查询接口或配置回调获取最终结果。

**Q14：任务状态有哪些值？**
`NOT_START(0)`、`SUBMITTED(1)`、`IN_PROGRESS(3)`、`FAILURE(4)`、`SUCCESS(5)`、`MODAL(6)`、`CANCEL(7)`。`SUCCESS`、`FAILURE`、`CANCEL` 为终止态。

**Q15：任务一直 SUBMITTED 怎么办？**
先检查账号在线、WebSocket、队列消费与任务消息 ID；超过超时时间仍无进展时取消并重提。管理端取消通常把任务置为失败（原因「取消任务」），不是 `CANCEL`。

**Q16：提示队列已满怎么办？**
让客户端退避重试，恢复掉线账号，或按容量增加账号/适度提高队列上限。不要只调大队列而不提升消费能力。

**Q17：失败任务会自动重试吗？**
Discord 任务没有自动重试；悠船可按配置开启失败自动重试。通用做法是修正提示词、账号或网络后由调用方重提，并控制重试频率。

**Q18：回调为什么没收到或重复？**
只有配置了全局 `NotifyHook` 或任务级 `notifyHook` 才会推送；推送失败不自动重试，重启或恢复后可能再次推送同一终态。接收方应按任务 ID 与状态做幂等。

### 配置与升级
**Q19：修改配置后什么时候生效？**
日志级别等设置在保存后立即生效；数据库、Redis 等基础配置通常需要重启；账号并发、队列等运行态参数部分要等重连或下次启动才完全生效。

**Q20：如何升级？**
Docker 使用升级脚本拉取镜像并重建容器，数据依赖挂载保留；也可在后台检查更新、下载后重启。升级前必须备份数据库、配置与附件，并准备上一版本镜像。

**Q21：升级后配置回到默认值怎么办？**
先检查 `data` 是否挂载、`data/mj.json` 是否被覆盖、Consul KV 是否被旧配置覆盖；恢复备份配置后重启。若数据库结构已变更，按回滚流程恢复数据库。

**Q22：多节点部署要注意什么？**
所有节点共享同一 Redis 与同一数据库，版本保持一致；启用 Consul 时共享配置与版本对齐；否则队列、缓存与配置会分裂。

### 数据与存储
**Q23：图片为什么 404？**
常见原因是未落地存储导致上游链接过期、本地附件未挂载、CDN 回源错误、对象存储私有读或文件被清理。按第九章第 6 节从 URL、存储类型、文件和 CDN 四层排查。

**Q24：任务数据会一直保留吗？**
默认最多保留 50 万条，超出后每次删除最早的 1000 条。需要长期留存时应在外部归档，不能依赖应用内任务表。

**Q25：如何做安全加固？**
关闭演示模式、注册与访客，重置管理员 Token，关闭或限制 Swagger，限制管理后台来源，开启限流，保护 Redis/数据库/对象存储凭据，并对日志脱敏。

## 术语表
### 绘图与任务相关术语

| 术语 | 含义 |
| --- | --- |
| Imagine | 文生图指令，提交提示词生成四张图 |
| Action | 任务动作类型，如 Imagine、Upscale、Variation、Blend、Describe、Video |
| U | Upscale，放大选中的单张图 |
| V | Variation，基于选中图生成变体 |
| R | Reroll，重新生成一组结果（Discord 按钮） |
| Remix | 在变体或放大时修改提示词的模式 |
| Blend | 多图混合 |
| Describe | 图生文，把图片转换为提示词 |
| Shorten | 缩短提示词并返回精简结果 |
| Seed | 生成结果对应的随机种子，可用于复现 |
| Fast | 快速模式，消耗快速额度 |
| Relax | 慢速模式，排队执行，通常不消耗快速额度 |
| Turbo | 极速模式，消耗更快但成本更高 |
| MODAL | 等待弹窗确认的任务状态，常见于 Remix 与局部重绘 |
| 终止态 | `SUCCESS`、`FAILURE`、`CANCEL`，不再继续推进 |

### 账号与调度相关术语

| 术语 | 含义 |
| --- | --- |
| 账号池 | 所有可用于绘图的账号集合 |
| 实例 | 某个账号在当前节点上的运行对象，按渠道 ID 区分 |
| 渠道 ID | 账号对应 Discord 频道或上游实例的标识 |
| Guild / Channel | Discord 服务器与频道 |
| CoreSize | 单账号最大同时执行任务数 |
| QueueSize | 单账号快速/默认队列的最大等待数 |
| RelaxQueueSize | 单账号慢速队列的最大等待数 |
| MaxQueueSize | 账号模型中的兼容字段，当前实际限流不使用它 |
| 选号规则 | `BestWaitIdle`、`Random`、`Weight`、`Polling`、`AccountFill` |
| 垂直领域 | 限定账号只服务特定领域或标签的配置 |
| 摸鱼时间 | 只接收变化任务、不接收新绘图任务的时间段 |
| 工作时间 | 允许创建实例并接收新任务的时间段 |
| 禁用原因 | 账号被自动或手动禁用时记录的原因 |

### 部署与运维相关术语

| 术语 | 含义 |
| --- | --- |
| 回调 | 任务状态变化时向业务方 POST 完整任务 JSON |
| NotifyHook | 全局或任务级的回调地址 |
| CDN | 内容分发网络，用于加速附件访问 |
| 对象存储 | OSS、COS、R2、S3 等附件存储服务 |
| Redis 队列 | 按账号与模式划分的任务等待队列 |
| 工作线程 | 从队列取任务并执行的后台消费单元 |
| Consul | 配置中心与服务发现组件 |
| Revision | 配置版本号，用于乐观锁与冲突检测 |
| 降级 | 依赖不可用时切换到本地 SQLite 或内存模式的运行时行为 |
| 限流 | 按 IP 与路径限制请求频率，超限返回 429 或 403 |
| 演示模式 | 跳过鉴权并默认开放 Swagger 的展示模式，禁止用于生产 |
